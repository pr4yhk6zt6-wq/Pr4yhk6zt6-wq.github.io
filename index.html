AI อาจให้ข้อมูลที่ไม่ถูกต้อง โปรดตรวจสอบข้อมูลสำคัญอีกครั้ง · ประวัติแชทเก็บอยู่ในเครื่องนี้เท่านั้น

การตั้งค่า
เชื่อมต่อกับ API ของผู้ให้บริการ AI ที่คุณเลือกได้อิสระ (รองรับมาตรฐาน OpenAI-compatible)
ปลายทาง API ของผู้ให้บริการ เช่น …/v1 — ต้องรองรับ POST /chat/completions
เก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ถูกส่งไปที่ใดนอกจากปลายทางที่คุณระบุ
ยังไม่ได้ทดสอบการเชื่อมต่อ
ใส่ชื่อโมเดลตามที่ผู้ให้บริการกำหนด — กดทดสอบการเชื่อมต่อเพื่อดึงรายชื่อโมเดลอัตโนมัติ (ถ้า API รองรับ GET /models)
สำหรับโมเดลที่รองรับ เช่น DeepSeek-R1, o-series — จะแสดง "การคิด" ก่อนคำตอบในหน้าต่างการทำงาน
เปิดไว้เพื่อให้ปุ่มดาวน์โหลด / ZIP / พรีวิว ได้ชื่อไฟล์ถูกต้อง
