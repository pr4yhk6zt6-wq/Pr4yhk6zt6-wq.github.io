โมเดลที่ใช้
กุญแจของผู้ให้บริการ

เลือกเจ้าที่ต้องการด้านล่าง แล้วกรอกกุญแจเฉพาะเจ้านั้นได้เลย ระบบจำแยกให้ทุกเจ้า จึงสลับกลับมาใช้ภายหลังได้โดยไม่ต้องวางใหม่

ใช้กับ API ที่รองรับรูปแบบ OpenAI Chat Completions เช่น Groq, xAI, Mistral, Together, Fireworks, DeepInfra, Cerebras และ Perplexity

Backend (แนะนำ)
ใช้ Backend แทนการยิงตรงเก็บ LLM Key ฝั่ง server · รองรับทุกค่าย รวม Gemini และ Claude

Frontend จะเรียก POST /api/chat ที่ Backend และแนบ provider ให้เองตามค่ายที่เลือก — วิธี deploy ดูใน backend/README.md

ค้นเว็บ

Gemini · Claude · OpenAI · OpenRouter ใช้กุญแจเดิมของโมเดล — ไม่ต้องซื้อ API เพิ่ม
DeepSeek ไม่มีค้นเว็บในตัว จึงใช้วิกิพีเดีย + อ่านหน้าเว็บฟรี (ใส่กุญแจ Jina หรือ Tavily ด้านล่างถ้าอยากได้ผลลัพธ์กว้างขึ้น)

รับกุญแจฟรีที่ jina.ai และ tavily.com — เก็บในเครื่องคุณเหมือนกุญแจอื่น
